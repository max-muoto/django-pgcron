## 0.2.0 (2026-10-18)

### Breaking changes

- Drop Python 3.10 support. Python 3.11 or newer is now required.

### Compatibility

- Extend the supported Python range through Python 3.15.
- Add support for Django 5.2 and 6.1. Django 5.2 requires PostgreSQL 14+;
  Django 6.1 requires PostgreSQL 15+.
- Add PostgreSQL 18 support.
